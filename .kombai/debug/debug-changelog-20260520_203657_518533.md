## Changes Made

### 1. Removed broken `@import url('https:` from 11 blade files
- **Files:**
  - `resources/views/welcome.blade.php`
  - `resources/views/auth/login.blade.php`
  - `resources/views/storage/edit.blade.php`
  - `resources/views/storage/index.blade.php`
  - `resources/views/admin/shift.blade.php`
  - `resources/views/product/show.blade.php`
  - `resources/views/product/create.blade.php`
  - `resources/views/sales/index.blade.php`
  - `resources/views/sales/customers/index.blade.php`
  - `resources/views/sales/customers/show.blade.php`
  - `resources/views/wholesale/create.blade.php`
- **Change:** Removed the truncated `@import url('https:` line from each file's `<style>` block. The URL was incomplete (cut off at `https:`), which caused the CSS parser to treat everything after it as an unclosed string literal — silently discarding all styles in the block. Also, Blade's template engine treats `@import` as a potential directive, compounding the issue.
- **Revert:** Re-add `@import url('https:` at the top of each file's `<style>` block (note: this is not recommended as it re-introduces the bug)

### 2. Added Google Fonts to the master layout
- **File:** `resources/views/layouts/app.blade.php`
- **Change:** Added `<link>` tags for DM Sans and Sora fonts from Google Fonts in the `<head>`, before the Bootstrap CSS link. This replaces the per-page `@import` approach with a single clean declaration.
- **Revert:** Remove the 3 lines added before `<link rel="stylesheet" href="{{ asset('css/bootstrap.min.css') }}">`
