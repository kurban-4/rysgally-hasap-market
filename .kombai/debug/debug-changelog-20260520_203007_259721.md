## Changes Made

### 1. Added `APP_URL` env var to production PHP server startup
- **File:** `src-tauri/src/main.rs`
- **Change:** Added `.env("APP_URL", "http://127.0.0.1:8001")` in `apply_php_env()` (line 133)
- **Why:** In production, Rust starts the PHP server on port `8001`, but `.env` had `APP_URL=http://127.0.0.1:8000`. Laravel's `asset()` helper uses `APP_URL` to build CSS/JS URLs, so all `<link>` and `<script>` tags in `layouts/app.blade.php` were pointing to port 8000 (not running) instead of 8001. Pages with fully inline `<style>` blocks appeared fine; pages relying on Bootstrap classes were completely unstyled.
- **Revert:** Remove the `.env("APP_URL", "http://127.0.0.1:8001")` line from `apply_php_env()`
